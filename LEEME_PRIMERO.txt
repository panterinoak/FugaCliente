FUGACLIENTE - PROYECTO DE EVALUACIÓN PARCIAL

1. Extrae todo el ZIP. Abre la carpeta FugaCliente en Visual Studio Code.
2. Abre Terminal > Nueva terminal. Debes ver package.json en esa carpeta.
3. Para ver el proyecto rápidamente ejecuta:
   npm ci
   npm run demo
4. Abre http://localhost:3000 en tu navegador.
   Correo: admin@fugacliente.local
   Contraseña: FugaCliente2026!

La DEMO usa datos temporales. Para cumplir la persistencia requerida en el PDF:
   Copia .env.example como .env y revisa sus variables.
   docker compose up -d --wait
   npm run db:setup
   npm run db:seed
   npm run doctor
   npm run dev

Lee README.md para pasos de Windows y para SQL Server/MongoDB ya instalados.
Los servicios de base de datos deben estar disponibles; no basta con ejecutar npm.
